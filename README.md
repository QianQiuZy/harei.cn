# 项目说明
将 harei.cn 网站的前端代码基于 Vue.js 进行重构
## 技术栈
- Vue 3
- Vuetify
- Vite
- Axios
- Vue3-photo-preview
- Pinia

## Node 版本要求
- Node.js 16.20.2+
- npm 8.19.4+


### 启动开发服务器

要使用热重载启动开发服务器，请运行以下命令。可在 [http:// localhost:3000](http:// localhost:3000) 访问服务器:
```bash
npm run dev
```

### 构建

```bash
npm run build
```
